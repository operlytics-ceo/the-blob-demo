# The Blob - Referrer Validation Demo

This demo page shows how The Blob's referrer-based access control works.

## How It Works

- **Clicking from this page:** Works ✅ - Browser sends referrer header
- **Copy/pasting URL directly:** Blocked ❌ - No referrer sent
